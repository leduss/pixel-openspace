# pixel-openspace

Your scheduled jobs as pixel-art workers in an open space, in your browser.

```bash
npx pixel-openspace
```

It reads your launchd agents (macOS), your crontab, and your systemd user timers (Linux), then opens the room on `http://127.0.0.1:4747`. Running jobs sit and type, failed ones smoke, idle ones go for coffee.

Run `npx pixel-openspace --help` for the options, and see the [main README](https://github.com/leduss/pixel-openspace#without-writing-code) for the settings file.

Live demo: https://pixel-openspace.vercel.app · MIT
